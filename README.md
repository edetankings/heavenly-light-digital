
# Risen Power Gospel Ministries (RPGM)

Official website of Risen Power Gospel Ministries, located in Effurun, Delta State, Nigeria.

A digital platform created to share the Gospel, connect with members and visitors, and provide access to church activities and resources.

## Website Features

- **Home:** Welcome to Risen Power Gospel Ministries.
- **About:** Learn more about the ministry.
- **Sermons:** Access sermons and spiritual teachings.
- **Live:** Watch live services and submit prayer requests.
- **Events:** Stay informed about upcoming church programmes.
- **Gallery:** Explore photographs and videos.
- **Testimonies:** Read and share testimonies.
- **Blog:** Access ministry articles and updates.
- **Contact:** Get in touch with the ministry.

## Administration

The website includes a protected administration dashboard for managing church content, including sermons, events, announcements, gallery media, testimonies, prayer requests and live-service settings.

## Technologies

- React and TypeScript
- TanStack Router
- Tailwind CSS
- GSAP
- Supabase
- Vercel

## Local Development

Install dependencies:

```bash
npm install
```

Create a local `.env` file using `.env.example` and configure the required environment variables.

Start the development server:

```bash
npm run dev
```

Build the website:

```bash
npm run build
```

## Security

Environment variables containing credentials must never be committed to GitHub. Administrative features require appropriate authentication and database permissions.

## Deployment

The website is configured for deployment on Vercel, with Supabase providing backend services.
